# Alvand Player 1.2.3 — Windows

## What's fixed / چه رفع شد

### English

- **Fixed: switching songs from Library while playing** — selecting another song now actually switches playback (the decoder is re-prepared whenever the playing item changes)
- **Fixed: artwork cache** — every song now shows its own cover in Library rows, Now Playing, the visualizer and the mini-player, even when covers load one after another
- Regression-tested with real PCM analysis (440 Hz vs 880 Hz sine tones), 340+ tests green
- Full UX audit fixes (P0–P2): real library tabs, i18n strings, professional queue (append / remove / reorder / clear), equalizer fader double-click reset, sleep timer, tooltips, crossfade, gradient theme, persistent visualizer settings
